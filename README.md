# وِرشة | واجهة إدارة الورش

واجهة React عربية باتجاه RTL للاتصال بواجهة MechanicShop ASP.NET Core API. المشروع محفوظ في مستودع مستقل عن الباك إند.

## طريقة التشغيل

راجع [RUNNING.md](RUNNING.md) لدليل التشغيل خطوة بخطوة على Windows PowerShell، بما يشمل إعداد عنوان API وتثبيت الحزم وتشغيل Vite.

## التقنية

React وTypeScript وVite وReact Router وTailwind CSS وTanStack Query وAxios وReact Hook Form وZod وLucide وRecharts.

## الوظائف المتصلة حاليًا

- تسجيل الدخول عبر `POST /identity/token/generate` والتحقق من المستخدم عبر `GET /identity/current-user/claims`.
- تجديد الرموز والخروج عبر نقاط الهوية في الخادم.
- ملخص اليوم من `GET /api/v1.0/dashboard/stats`.
- الفروع المتاحة للحساب من `GET /api/v1.0/branches`.
- أوامر الشغل من `GET /api/v1.0/workorders`.
- واجهة RTL عربية متجاوبة مع حالات التحميل والخطأ والبيانات الفارغة.

## قيود التنفيذ

الخادم هو مصدر الصلاحيات النهائي. لا توجد واجهة API مستقلة للتقارير التاريخية أو سجل النشاط أو قائمة الفواتير؛ لذلك لا تعرض الواجهة بيانات تمثيلية لهذه الميزات. بقية عمليات العملاء والموظفين والمهام والفواتير تحتاج استكمال الربط قبل اعتبارها منجزة.
